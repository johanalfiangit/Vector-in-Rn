# Vector-in-Rn
Vector in Rn
Fitur pembelajaran yang tersedia
1. Materi inti
- Vektor dalam \(R^n\).
- Operasi aljabar vektor.
- Penjumlahan vektor secara geometris.
- Panjang atau norma vektor.
- Jarak antara dua titik.
2. Visualisasi interaktif
- Grafik vektor 2D.
- Proyeksi vektor 3D isometrik.
- Visualisasi arah dan resultan vektor.
- Perubahan grafik secara langsung ketika angka diubah.
3. Kalkulator vektor
- Penjumlahan \(u+v\).
- Pengurangan \(u-v\).
- Perkalian skalar \(ku\).
- Perhitungan norma vektor.
- Hasil perhitungan beserta tahapan matematis.
4. 30 modul studi kasus
- Manufaktur, robotika, AGV, conveyor, dan material handling.
- Mekanika, gaya, struktur, dan permesinan.
- Logistik, pergudangan, dan transportasi.
- Aeronautika, maritim, energi, dan fluida.
- Geometri dan aplikasi matematika teknik umum.
Cara menjalankan
1. Unduh file HTML.
2. Buka menggunakan Google Chrome atau Microsoft Edge.
3. Tidak memerlukan instalasi aplikasi maupun koneksi internet.
4. Pilih salah satu dari 30 studi kasus.
5. Ubah angka pada kolom input dan tekan tombol perhitungan.
